# Campus Literary Festival Website

A responsive single-page website for a campus literary festival, featuring:

- Event schedule for a three-day program
- Guest speaker highlights
- Registration form with client-side validation and success messaging

## Files

- `index.html` — page structure and content sections
- `styles.css` — visual design and responsive layout
- `script.js` — registration form interaction logic

## Run locally

Open `index.html` in any modern web browser.
